## Featured Project

### Absurd Exchange
**A stock market for things that have no business being stocks.**

A trading simulator where users buy and sell everyday items like garlic bread or a goose. I’m building the application across its database, backend, and user interface.

- **Trading:** Virtual wallets, portfolios, buy/sell transactions, and pending orders.
- **Data:** Historical prices, portfolio analytics, and leaderboards.
- **Backend:** Relational database design, REST APIs, JWT authentication, and transaction-safe processing.

`Python` `FastAPI` `PostgreSQL` `SQLAlchemy` `React Native` `React`
